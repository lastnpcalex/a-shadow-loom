Workspace-owned extensions

                        
                    

                    
Register an exo-extension.json by absolute path. EXO stores only the reference; the owning workspace retains its manifest, commands, Git history, and update policy.

                    

                        
                        
                    

                    

                    

                

                

                    
Manifest shape

                    
{
  "schema_version": 1,
  "id": "my-project.service",
  "name": "My Project Service",
  "kind": "service",
  "workspace_root": ".",
  "cwd": ".",
  "start": {"command": ["python", "server.py"]},
  "health": {"url": "http://127.0.0.1:8123/health"},
  "update": {"command": ["git", "pull", "--ff-only"]}
}

                    
Commands are argument arrays, never shell strings. Working directories stay inside the declared workspace. Health probes are loopback-only. Update and stop are explicit human actions.

Loom Conversation Modes

                    
Loom — Claude Code via the Anthropic API; the model dropdown also carries Codex and Antigravity groups, switchable mid-conversation. Braid — Claude Code on the local llama-server. Goose — the ACP harness with OpenRouter, llama-server and Dream backends. Weave — structured RP with characters, personas, and the OODA state harness.

                    
Everything shares one branching tree, one search index, one chat surface: highlight any message text to quote it in your next send; attach files; queue messages mid-generation; branch, fork, and regenerate without losing anything.
